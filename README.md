# Morpholio Trace CAD - Android Studio Project

## How to Build & Run
1. Extract `MorpholioTraceAndroid.zip`.
2. Open **Android Studio** (Iguana / Jellyfish or newer) and select **Open**.
3. Choose the extracted `MorpholioTraceAndroid` folder and let Gradle sync automatically.
4. Click **Run 'app'** (`Shift + F10`) on an Android Emulator or physical device (API 26+).
